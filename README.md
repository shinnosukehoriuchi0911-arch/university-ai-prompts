# 大学生のための AI 課題管理プロンプト（無料4本）

課題が重なった週に、ChatGPT・Claude・Gemini などにそのまま貼って使えるプロンプトです。
【】の中を自分の内容に書き換えてください。

> ⚠ AI の出力をそのまま提出するのではなく、**計画づくり・分解・確認**に使う前提です。
> 生成AIの利用ルールは授業ごとに違うので、シラバスと先生の指示を先に確認してください。

## 1. 今週の課題の優先順位づけ
```
以下は今週の課題一覧です。締切・所要時間（推定）・配点を考慮し、やる順番と1日ごとの割り振りを表にしてください。1日の作業可能時間は【3】時間です。
【課題を箇条書き：科目／内容／締切／所要時間／配点】
```
**コツ**：所要時間がわからない課題は「不明」と書けば、AI が見積もりの質問をしてくれます。バイトの日は「【曜日】は1時間だけ」と足すと現実的な表になります。

**AIの出力例（Claude Sonnet で実行、2026-11-08）**：上のプロンプトを、仮の課題3件（英語レポート：金曜締切・6時間・20点／統計の演習：木曜締切・5時間・30点／ゼミ発表：来週月曜・所要時間不明・15点。※すべて架空、今日は月曜、1日3時間）を入れて実際に実行した結果です。長いため一部を省略しています（「（中略）」）。実際の結果は入力内容で変わります。

> 1. **統計**（木曜締切、30点、1時間あたり6点）を最優先にします。締切が最も早く、1時間あたりの得点も最大です。
> 2. **英語**（金曜締切、20点、6時間）は火曜から着手し、木曜までに書き終えます。
> 3. **ゼミ**（来週月曜締切、15点、所要時間不明）は後回しにします。ただし不明なので、木曜に構成だけ作って所要時間を見積もります。

| 日 | 統計 | 英語 | ゼミ | 計 | 目標 |
|---|---|---|---|---|---|
| 月（今日） | 3h | | | 3h | 問1〜3を解く |
| 火 | 2h | 1h | | 3h | 統計を完了。英語はテーマ決めと構成案 |
| 水 | | 3h | | 3h | 英語の本文を約1000語まで書く |
| 木 | 提出 | 2h | 1h | 3h | 英語を書き終える。ゼミは構成を作り、所要時間を見積もる |

（中略：金〜翌月曜の行と「ポイント」の節）

<sub>実行：`claude -p --model sonnet`（標準入力にプロンプトを渡す）、所要約19秒、2026-11-08。</sub>

## 2. 大きい課題の分解
```
課題「【内容】」を、締切【日付】までに終わらせたい。30分単位のタスクに分解し、日付つきチェックリストにしてください。最初の30分でやることを具体的に1つ示して。
```
**コツ**：チェックリストはカレンダーや課題管理アプリにそのまま貼れます。「最初の30分」だけはその日のうちに。

## 3. 先延ばし脱出
```
【課題】に手をつけられません。理由は【理由】。5分でできる最初の一歩を3案出し、一番楽なものから始める声かけを1文ください。
```
**コツ**：理由は正直に（「難しそう」「何を書けばいいかわからない」「やる気がない」）。理由で出てくる一歩が変わります。

## 4. 締切前日の最終チェック
```
課題の指示文を貼ります。提出前チェックリスト（形式・字数・引用・ファイル名・提出方法）を作り、私の成果物が満たしているか確認する質問を5つください。
【指示文】
```
**コツ**：指示文はシラバスや課題ページから**そのまま**貼ります。言い換えると形式や字数の条件が抜けやすくなります。

- テンプレート：[prompts/academic-ai-disclosure.md](prompts/academic-ai-disclosure.md)

## 6. 【付録】英語論文校正＆学術文体洗練プロンプト（無料版）
自分で書いた英語論文の下書きを、学術的な文体に整えるためのプロンプトです（内容や主張はAIに作らせない前提。投稿先の雑誌・学会のAI利用ポリシーと、指導教員の指示を先に確認してください）。
- プロンプト：[prompts/academic-paper-polishing.md](prompts/academic-paper-polishing.md)

## 7. 【付録】AI誤検知対策・学術対話監査プロンプト（無料版）
AI検出器（Turnitin等）で誤って「AIが書いた」と判定されたときに説明できるよう、AIを思考補助としてどう使ったかの記録を作るプロンプトです（検出そのものを防ぐものではありません）。
- プロンプト：[prompts/ai-detection-defense.md](prompts/ai-detection-defense.md)

## 8. 【付録】AI生成コード ライセンス汚染防止プロンプト（無料版）
プログラミング課題やOSS開発でAI（Copilot等）を使う際、GPL/AGPLなどのライセンスの混入やシークレットの漏れがないかを自分で点検するためのプロンプトです（最終的な判断は自分か指導者が行ってください）。
- プロンプト：[prompts/ai-code-license-audit.md](prompts/ai-code-license-audit.md)
